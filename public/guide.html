🇲🇱 Guide testeurs ML CHOP

Marketplace + livraison à Bamako. 5 minutes de lecture, merci de tester !

Ouvrir l'application →

1. Créer un compte

Choisir un espace (Client, Vendeur ou Livreur) → « Créer un compte » → nom, téléphone, mot de passe.

Code OTP : 1234 (aucun SMS n'est envoyé).

  • Client : actif immédiatement.
  • Vendeur / Livreur : en attente de validation par l'admin (faite à la main).

2. Règles importantes

  • Paiements simulés : aucun argent ne circule.
  • Maximum 5 produits différents par commande.
  • Pas de vraies données personnelles : nom et numéro inventés.
  • Pas de scripts de masse : le quota gratuit est partagé par les 50 testeurs.
  • Les tests de sécurité sont bienvenus, mais une faille se signale en privé.

3. Quoi tester

Client

  • Inscription, déconnexion, reconnexion
  • Catalogue, catégories, fiche produit, avis, favoris
  • Panier (quantités, retrait, limite de 5 produits) et commande avec chaque moyen de paiement
  • Suivi de commande : statuts, notifications, code de livraison

Vendeur (après validation)

  • Ajouter, modifier, masquer, supprimer un produit
  • Confirmer, préparer, transmettre ou refuser une commande ; revenus

Livreur (après validation)

  • Accepter une mission → récupération → arrivée → code du client → livrée
  • Géolocalisation (autoriser le navigateur), historique, gains

Tous

  • Téléphone et PC, rechargement de la page (la session doit rester ouverte)
  • Messages d'erreur compréhensibles
  • Essayer d'accéder aux données des autres (doit être refusé)

4. Signaler un problème

Dans l'app : bouton 🐞 en bas à droite (une fois connecté) → Bug, Suggestion ou Faille de sécurité.

Sur GitHub : ouvrir une issue.

Faille de sécurité : uniquement en privé (bouton 🐞 « Faille de sécurité » ou signalement privé GitHub).

Un bon signalement : vos étapes, ce que vous attendiez, ce qui s'est passé, votre rôle.
